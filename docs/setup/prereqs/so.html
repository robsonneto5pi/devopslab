Sistema Operacional

Versão mínima do Windows necessária para rodar Docker Desktop, Minikube e kubectl.

1

Requisito mínimo

O Docker Desktop com backend WSL 2 exige uma das versões abaixo:

Windows 10 64-bit
Build 19041 (versão 2004) ou superior — Home, Pro ou Enterprise.
Windows 11 64-bit
Qualquer edição (Home, Pro, Enterprise). Recomendado para novos setups.
✅ Ambiente validado neste lab: Windows 11 Enterprise · Build 26200 · 64-bit
2

Como verificar sua versão

Execute um dos métodos abaixo para confirmar a versão instalada:

# Método 1 — caixa de diálogo winver (Win + R)
winver

# Método 2 — PowerShell
Get-WmiObject Win32_OperatingSystem | Select-Object Caption, Version, BuildNumber, OSArchitecture

O campo BuildNumber deve ser 19041 ou superior. No Windows 11 será 22000 ou superior.

3

Como atualizar

Se o seu Windows estiver abaixo do requisito mínimo, atualize pelo Windows Update:

# Abrir as configurações do Windows Update diretamente
Start-Process "ms-settings:windowsupdate"

Navegue até Configurações → Windows Update e instale todas as atualizações disponíveis. Após o reboot, verifique novamente com winver.

⚠ Após atualizar o Windows, pode ser necessário reiniciar o computador mais de uma vez antes de todas as atualizações serem aplicadas.
