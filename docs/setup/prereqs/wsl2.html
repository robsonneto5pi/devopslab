1

O que é e por que é necessário

O WSL 2 (Windows Subsystem for Linux v2) é o componente do Windows que permite executar um kernel Linux real dentro do Windows. O Docker Desktop o usa como backend para rodar os containers, e o Minikube cria o nó do cluster Kubernetes dentro de um container Docker — que por sua vez roda no WSL 2.

Versão mínima
WSL 2.x · Kernel 5.15+
Validado neste lab
WSL 2.6.1.0 · Kernel 6.6.87.2-1 · WSLg 1.0.66
✅ No Windows 11, o WSL 2 geralmente já está habilitado por padrão. No Windows 10 (Build 19041+) pode ser necessário instalá-lo manualmente.
2

Como verificar se já está instalado

# Exibe versão do WSL, kernel e distribuições instaladas
wsl --version

# Lista todas as distribuições e suas versões WSL
wsl --list --verbose

Se o comando retornar a versão (ex: Versão do WSL: 2.6.1.0), o WSL 2 já está instalado. Se retornar erro ou a versão for 1, siga os passos abaixo.

3

Instalar o WSL 2 (caso não esteja instalado)

Abra o PowerShell como Administrador e execute o comando abaixo. Ele habilita o WSL, instala o kernel Linux mais recente e define o WSL 2 como padrão: 

# Instala o WSL 2 com um único comando (Windows 10 Build 19041+ / Windows 11)
wsl --install
⚠ Um reboot é necessário após a instalação para que o kernel do WSL 2 seja carregado.

Se precisar instalar passo a passo (Windows 10 versões mais antigas), execute na ordem:

# Passo 1 — habilitar o componente WSL
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

# Passo 2 — habilitar a plataforma de máquina virtual (necessário para WSL 2)
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# Passo 3 — reiniciar e depois definir WSL 2 como padrão
wsl --set-default-version 2
4

Atualizar o WSL para a versão mais recente

Se o WSL já estiver instalado mas em uma versão antiga, atualize com:

# Atualiza o WSL e o kernel Linux para a versão mais recente
wsl --update

# Confirmar a versão após a atualização
wsl --version
ⓘ O kernel do WSL 2 é entregue via Windows Update ou pelo próprio comando wsl --update. Não é necessário baixar nenhum instalador separado em versões recentes do Windows 10/11.
