Requisito mínimo

O Chocolatey (gerenciador de pacotes usado neste lab) exige o .NET Framework 4.8 ou superior. O .NET Framework 4.8 já vem pré-instalado no Windows 10 (versão 1903+) e em todas as edições do Windows 11.

.NET Framework 4.8+
Exigido pelo Chocolatey. Já incluído no Windows 10 1903+ e Windows 11.
Validado neste lab
.NET Framework 4.8.09221 (Release 533509) · .NET Runtime 9.0.18 · SDK 9.0.316
✅ Se você estiver no Windows 10 Build 19041+ ou Windows 11, o .NET Framework 4.8 já está instalado — nenhuma ação é necessária.
2

Como verificar a versão instalada

# Verificar versão do .NET Framework via registro do Windows
Get-ChildItem 'HKLM:\SOFTWARE\Microsoft\NET Framework Setup\NDP' -Recurse |
  Get-ItemProperty -Name Version, Release -ErrorAction SilentlyContinue |
  Where-Object { $_.PSChildName -match '^(?!S)\p{L}' } |
  Select-Object PSChildName, Version, Release |
  Format-Table -AutoSize

# Verificar versão do .NET (Runtime moderno)
dotnet --version
dotnet --list-runtimes

No resultado, o campo Release indica a versão exata. O valor 528040 corresponde ao .NET Framework 4.8 RTM. Qualquer valor igual ou superior está dentro do requisito.

Release 528040
.NET Framework 4.8 — versão de lançamento (mínimo exigido)
Release 533509+
.NET Framework 4.8.1 — com atualizações (validado neste lab: 533509)
3

Instalar ou atualizar o .NET Framework

Se o seu sistema não possui o .NET Framework 4.8 (Release < 528040), instale-o manualmente. Baixe o instalador offline na página oficial da Microsoft:

ⓘ Acesse aka.ms/dotnet48 no navegador para baixar o instalador offline do .NET Framework 4.8 diretamente da Microsoft.

Alternativamente, instale ou atualize via Windows Update:

# Abrir o Windows Update
Start-Process "ms-settings:windowsupdate"

O .NET Framework 4.8 é entregue como atualização de sistema. Instale todas as atualizações disponíveis e reinicie.

ⓘ Para instalar o .NET Runtime moderno (opcional para este lab, mas recomendado), use o Chocolatey após ele estar configurado: 
# Instalar .NET Runtime mais recente via Chocolatey (opcional)
choco install dotnet-runtime -y
