Virtualização

Habilitar VirtualMachinePlatform no Windows e virtualização na BIOS/UEFI — necessário para WSL 2 e Docker Desktop.

1

O que precisa estar habilitado

Para o Docker Desktop funcionar com o driver WSL 2, dois níveis de virtualização precisam estar ativos:

BIOS / UEFI
Intel VT-x ou AMD-V — suporte a virtualização de hardware no processador. Deve ser habilitado nas configurações da placa-mãe.
VirtualMachinePlatform
Recurso opcional do Windows que expõe a camada de hipervisor ao WSL 2. Habilitado via PowerShell ou Painel de Controle.
✅ Ambiente validado neste lab: HypervisorPresent: True · VirtualMachinePlatform: Enabled
2

Como verificar o estado atual

# Verifica se o hipervisor está ativo e o estado do VirtualMachinePlatform
systeminfo | findstr /C:"Hyper-V"

# Alternativa via PowerShell — mais detalhado
Get-WmiObject Win32_ComputerSystem | Select-Object HypervisorPresent

Get-WindowsOptionalFeature -Online | Where-Object { $_.FeatureName -match "VirtualMachine|HyperV" } |
  Select-Object FeatureName, State

Espere ver HypervisorPresent: True e VirtualMachinePlatform: Enabled. Se ambos estiverem corretos, pode seguir para os próximos passos do lab.

ⓘ Você também pode verificar pelo Gerenciador de Tarefas: aba Desempenho → CPU → campo Virtualização: Habilitada.
3

Habilitar VirtualMachinePlatform no Windows

Abra o PowerShell como Administrador e execute:

# Habilitar a plataforma de máquina virtual (WSL 2 backend)
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

# Confirmar após o reboot
Get-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform | Select-Object State
⚠ Um reboot é necessário para que a feature seja ativada.

Também é possível habilitar pela interface gráfica: Painel de Controle → Programas → Ativar ou desativar recursos do Windows → Plataforma de Máquina Virtual → marcar a caixa → OK → Reiniciar.

4

Habilitar virtualização na BIOS / UEFI

Se o campo Virtualização no Gerenciador de Tarefas mostrar Desabilitada, é preciso entrar na BIOS/UEFI do computador e habilitar manualmente. 

# Reiniciar direto nas configurações de firmware UEFI (Windows 10/11)
shutdown /r /fw /t 0

Dentro da BIOS/UEFI, procure por uma das opções abaixo (o nome varia por fabricante):

Intel
Advanced → CPU Configuration → Intel Virtualization Technology (VT-x) → Enabled
AMD
Advanced → CPU Configuration → SVM Mode ou AMD-V → Enabled
ⓘ Salve as alterações com F10 (ou conforme indicado na BIOS) e reinicie. Após o reboot, verifique novamente com o Gerenciador de Tarefas.
